# Security policy

## Supported versions

Security fixes target the latest minor of the current major. Upgrade older minors to receive fixes. Older majors and prereleases are unsupported unless an explicit support agreement states otherwise. No response-time guarantee is offered.

## Reporting a vulnerability

Do not report a suspected vulnerability in a public issue.

Use GitHub private vulnerability reporting on the [package repository](https://github.com/ehven-consultants-npm-products/ehven-lanes/security/advisories). Sign in and choose **Report a vulnerability**. Reports are private to the reporting collaboration and authorized maintainers; do not include credentials or unrelated private data.

For a routine usage problem, use the repository’s public issue tracker. No response-time guarantee is offered.

Include:

- The affected package version.
- The relevant installation or delivery method.
- A reproducible demonstration.
- The practical impact.
- Any suggested mitigation.

The package includes CSS and an optional explicitly initialized browser module. The module measures and positions direct-child elements and observes layout/content changes; it does not make remote requests or use persistent storage. Supply-chain, publication, integrity, unexpected DOM effects and unsafe rendering issues are treated as security concerns.
